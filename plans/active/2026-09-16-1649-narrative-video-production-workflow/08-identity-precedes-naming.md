# Candidate: Identity precedes naming

Companion to [`_plan.md`](_plan.md)。**候選原則，不是 workflow schema。** Phase 3 **不**改 `narrative-video-production`。  
觀察：[`evidence/2026-09-17-identity-precedes-naming.md`](evidence/2026-09-17-identity-precedes-naming.md)。

原則：身份先於名稱；名稱是後續證據解析出的結果，不是建立角色時的必要前提。

```text
observed entity → identity cluster → character identity → canonical name → series_cast
```

`series_cast` 是**已解析**角色表，不是第一集的發現資料。Face／voice 是 evidence，不是 identity key。歷史 observation 不因後來命名而覆寫。
