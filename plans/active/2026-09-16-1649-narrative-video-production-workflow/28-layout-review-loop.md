# Candidate: Bounded layout review loop

Companion to [`27-typography-layout-profile.md`](27-typography-layout-profile.md)、[`18-episode-vs-knowledge-accumulation.md`](18-episode-vs-knowledge-accumulation.md)。**候選 loop，不是 AI 直接改字級，也不是 workflow schema。**  
觀察：[`evidence/2026-09-22-layout-review-loop.md`](evidence/2026-09-22-layout-review-loop.md)。

AI 只產 review evidence＋`adjustment_candidates`；Mechanical engine 執行 render／驗證。分階段：mechanical_fit → cue_layout → visual_review → temporal_stability → scene_consistency → episode_review。FAIL 只重跑該層並標 responsible parameter。**Iteration budget**；撞 profile min／absolute bound 交 `contract_gap`／`data_insufficient`（三層字級見 [`34-font-size-layers-visual-scale.md`](34-font-size-layers-visual-scale.md)）。AI 只建議方向與區間，不得指定 absolute floor 的字級。舒服感不得直接寫 profile：Observation → candidate → independent verify → Learning Inbox → 跨集才 promotion。Speech timing 是另一條 loop：[`29-speech-timing-authority.md`](29-speech-timing-authority.md)。Phase 3 **不**把 TTS 寫進 lifecycle 新 stage。
