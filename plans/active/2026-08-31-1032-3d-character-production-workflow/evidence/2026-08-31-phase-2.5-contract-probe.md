# Phase 2.5 contract probe — fillability 結論

非正式 dogfood。Filled instances 留在 consumer `<PROJECT_ROOT>`（相對 `docs/` 下的 probe 目錄）。本檔不寫專案名、絕對路徑或素材檔名。

判斷標準：能否不用新規則、不塞空欄、不偷讀 scenario heuristic，就把 contract 填完。

## 結論

**Contract probe PASS ≠ workflow PASS。**

Stakeholder（2026-08-31）：Artifact contracts are sufficient to represent observed
real-world 3D character production data without schema revision or heuristic
invention; observed absence remains non-passing.

不是「3D character production workflow validated」。不因此建立 workflow / route /
glossary / executable-contract。Phase 3 **未授權**。

Closure evidence：commit `22626de9`（fillability）＋本檔區別鎖定。

## 四個觀察點

| 觀察 | 填得出來？ | 說明 |
| --- | --- | --- |
| Identity Acceptance | 是 | `accepted_attributes` / `blocking_attributes` / `evidence` / `validity` 都能填。專案筆記只有辨識點清單、沒有 attribute pass/fail → `decision: hold`，非 blocking fail。不發明 PASS。 |
| mutation_event | 是 | 一次真實 mesh 修腳／分趾對得上 `mesh_repair`。未做 identity 視角抽查 → 只能走 `visual_drift` 分支 → `re_review_required`。頭髮重建／換臉未發生，不必硬造 event。 |
| artifact-gates | 是 | eligibility 只讀 `decision`、`blocking_attributes`、`validity`、`mesh_qa.decision`、`deformation.decision`、readback、`fresh_reviewer`。不必讀 scenario 句子。`hold` + `validity: current` → **不得**進 mesh_qa。 |
| Candidate Record | 是 | 一份 `accepted`（現行全身底模）+ 一份 `rejected`（先前肢體黏連，reason 齊）。`seed: unavailable`、`generation_settings.availability: partial` 可填，未捏造。 |

## 未填成 PASS 的欄（不是缺欄）

- Mesh：未做破面檢查 → `holes_or_nonmanifold: fail`（`not_inspected`），故 `mesh_qa.decision: fail`。
- Deformation 最小充分 set：專案沒有這六項觀察紀錄 → 各項 `fail` / `not_observed`，`decision: fail`。
- Pack：檔案可匯出 ≠ completion；`fresh_reviewer: false`；readback 多項 fail；maturity `prototype`。

## Architecture smell？

無。Gate 沒有回頭去讀 heuristic。Identity 沒有為了讓歷史施工變綠而改成 `accepted`。
