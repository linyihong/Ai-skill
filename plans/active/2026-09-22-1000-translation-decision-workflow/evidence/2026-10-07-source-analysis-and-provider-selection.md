# Source analysis and provider selection boundaries

## Selection is a runtime fact

A local-only probe proves its own provider selection, not the production
adapter's persisted setting. Verify effective service selection and independent
persisted readback separately. A scoped provider update must not include
credentials or unrelated settings; policy tests still need configured-credential
negative cases so fallback and repair cannot override explicit selection.

## Capability prompt versus source analysis

Replacing recap framing with a general faithful-translation instruction can
leave a noun-referent failure unchanged. That is negative repair evidence, not
permission to add a case-specific glossary or deploy an unproven prompt.

A source-analysis probe should record grammatical/semantic structure as an
artifact before realization. Validate source-span anchoring and schema, compile
only allowlisted fields as candidate/constraint input, and retain the original
observation. Model-generated structure is a candidate analysis, not independent
semantic truth. Valid JSON and anchored words do not prove correct reference
resolution, head classification or target meaning; Finality remains separate.

## Diagnostic evidence retention

Verify the installed adapter entry point and basic plumbing before expensive
model initialization. Persist generated output before parsing or schema checks,
including invalid output and its disposition; parser failure must not erase
evidence or abort unrelated diagnostic cases silently. Retain producer/source
version scope when probe code changes. Schema rejection is not proof of a
model-runtime crash or semantic failure; distinguish these verdicts.

## Acceptance status

Provider selection/readback and scoped probe plumbing support adapter progress.
They do not close the source-analysis, complete TDR, semantic/content or NVP
render gate. Existing [projection/orthography evidence](2026-10-07-target-orthography-boundaries.md)
remains distinct from pure-source translation quality. No canonical workflow
step, new actor, fixed glossary or automatic acceptance rule is introduced.

## Structured candidate observation

A local source-analysis/realization probe restored a nominal target referent
where capability-prompt changes did not. Other records exceeded the requested
schema, and analysis/realization labels exposed unresolved field-scope or
semantic consistency. Invalid rows remain retained, not accepted or silently
translated. This is a candidate strategy, not production repair evidence.
Clarify structural field ownership and verify reference/meaning independently
before deployment; source-span anchoring alone cannot close these gates.
