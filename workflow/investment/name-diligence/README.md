# Sub-flow: name-diligence

單一標的公開資訊 diligence。

## 步驟

1. Intake：ticker／公司；研究帳 watchlist（user-local）  
2. Risk tier（通常 Yellow）  
3. Pass 1  
4. Research：A／B 揭露優先；新聞模板；筆記對照（D 不可獨撐）  
5. Pass 2：diligence 結論用 uncertainty labels  
6. Gates  

## 產出

- Diligence card（業務／風險／催化／未決）  
- Evidence-ledger  
- Contrast table（若有研究帳）  
- Human selection（是否要自己跟進／下單不在此執行）
