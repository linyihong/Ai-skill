# Sub-flow: theme-research

產業／供應鏈主題 → thesis note＋地圖＋catalyst／falsify。

## 步驟

1. Intake：主題定義＋排除＋市場  
2. Risk tier  
3. Pass 1：決策點（主題是否值得深挖、是否落到標的）  
4. Research：[`theme-and-supply-chain.md`](../../../analysis/investment/theme-and-supply-chain.md)＋[`news-trend-summary.md`](../../../analysis/investment/news-trend-summary.md)＋可選 [`researcher-note-contrast.md`](../../../analysis/investment/researcher-note-contrast.md)  
5. Pass 2：thesis 強度 ≤ evidence  
6. Validate gates  

## 產出

- Theme definition／exclusions  
- Node／choke 表（authority＋as-of）  
- Catalysts／what would falsify  
- Optional candidate names（非買入清單口吻）  
- Evidence-ledger  

DVA：可驗證報告時建議強制。
