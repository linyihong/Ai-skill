# Sub-flow: need-framing

澄清「要分析什麼」→ 建議 task type 路徑。

## 步驟

1. Intake S0  
2. 列出可能 task type 與差異  
3. 請使用者選一條（或標混合 → 拆 primary/secondary）  
4. 輸出 Framing note＋下一步 intake 缺口  

## 產出

- Investment Task Frame  
- 建議路徑（單一或拆分）  
- Blocking questions  

不產配置建議。方法：無強制 analysis；需要時讀 [`../../../analysis/investment/README.md`](../../../analysis/investment/README.md)。
