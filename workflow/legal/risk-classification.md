# Risk Classification & Escalation（Green / Yellow / Red）

本檔是 Stage 2 的 canonical source。Risk tier **決定產出的深度**，不是附錄的免責聲明。

> **P0**：Red tier 必須停止實質建議。這不是保守，是因為錯誤建議在這些領域造成的損害
> 不可逆，且完整的輸出會讓使用者不再尋求執業律師。

## Tier 判定表

判定規則：**取最高命中的 tier**（任一 Red 條件命中即 Red，不因其他條件是 Green 而降級）。

### 🟢 Green — 完整產出

| 條件 | 例 |
| --- | --- |
| 標準商務合約、單一法域、金額在使用者日常決策範圍內 | 雙向 NDA、一般服務合約、小額財物採購 |
| 有官方或業界成熟範本可對照 | 政府採購範本的標準條款、常見 SaaS 訂閱 |
| 無強制法特殊領域暴露 | 不涉勞動／消保／競爭／個資特殊處理 |
| MOU / LOI 且明確無拘束力 | 合作意向書 |

**產出**：完整草稿或審閱意見 + 風險登記表 + disclaimer。

### 🟡 Yellow — 產出但標明必須覆核

| 條件 | 為什麼 |
| --- | --- |
| **跨境**（≥2 法域） | 準據法／執行地／強制法交互作用複雜 |
| **高金額**（相對使用者規模顯著） | 錯誤成本高 |
| **智慧財產**歸屬、授權或 indemnity | 條款效果長期且難回復 |
| **獨家性**條款（獨家經銷、排他採購） | 競爭法風險 |
| **個資／資料跨境**處理 | 各法域強制規定 + 罰則高 |
| **政府採購** | 法定程序 + 罰則 + 停權風險 |
| 使用**未查證**的法規主張（confidence=unverified） | 前提可能錯 |
| audit / 稽核權、單方變更權、自動續約 + 難終止 | 常被忽略的高影響條款 |

**產出**：完整草稿或審閱意見，但**必須**：
1. 在產出開頭列出「需律師覆核的具體條款清單」（不是籠統一句）。
2. 每個 Yellow 觸發條件對應到具體條款與具體風險。
3. `unverified` 的法規主張明確標記，不以確定語氣呈現。

### 🔴 Red — 停止實質建議，只做升級

| 條件 | 為什麼不做 |
| --- | --- |
| **勞動個案**（解僱、懲戒、競業執行、職災、性平案件） | 程序瑕疵即敗訴；強制法密集；個案事實決定結果 |
| **股權 / 投資 / 增減資 / 選擇權** | 公司法與證券法強制規定；稅務連動 |
| **併購（M&A）／重大資產處分** | 盡職調查、稅務、競爭法申報缺一不可 |
| **訴訟 / 仲裁進行中或已發生爭議** | 有時效與程序期限；一句話可能構成不利自認 |
| **政府行政處分、調查、裁罰** | 有法定救濟期間；程序性極強 |
| **刑事風險**（背信、侵占、營業秘密刑責、洗錢） | 不可逆 |
| **制裁名單命中**（OFAC / EU / UN / 出口管制實體清單） | 交易本身可能違法 |
| **稅務規劃 / 移轉訂價** | 需會計師與稅務律師 |
| 使用者要求**代為對外發出**法律文件（存證信函、律師函） | 對外行為，且屬律師業務範圍 |

**Red 的產出（`Escalation Card`）**——仍要有用，不是拒絕：

```markdown
## Escalation Card
- Risk tier: 🔴 Red
- 觸發條件: <命中哪一條>
- 為什麼本流程不出實質建議: <一句，不重複勸誡>
- 時效性提醒: <是否有法定期間／救濟期限需要立刻確認>
- 需要準備的事實與文件: <清單>
- 建議的專業人士類型: <例：勞動法律師 / 地方勞工行政機關調解 / 稅務律師 + 會計師>
- 本流程仍可協助的部分: <例：整理時序表、彙整既有文件清單、列出待確認事實>
```

**禁止**：草擬存證信函或律師函內容；列出具體條號作為請求權依據；評估勝訴機率或
和解金額區間；照常輸出建議只在結尾加免責聲明。

## Tier 升降規則

| 情境 | 處置 |
| --- | --- |
| 使用者堅持要 Red 領域的實質建議 | 說明界線一次，提供 Escalation Card 與可協助部分，不重複勸誡；不因堅持而改變 tier |
| 任務中途發現新的 Red 條件 | 立即升 Red，停止該部分產出，說明是什麼觸發的 |
| Yellow 的 `unverified` 主張經查證確認 | 該項可降級標記，但 tier 不因此降 |
| 使用者說「只是內部評估，不會真的用」 | tier 不降。內部評估同樣會影響決策 |

## 與其他 stage 的關係

- Stage 2 判定 tier → Red 時 **短路** Stage 4–7（見 [`execution-flow.md`](execution-flow.md)）。
- Stage 4 背調的 `SANCTIONS_HIT` flag → 直接升 Red。
- Stage 5 的 `unverified` 法規主張 → 至少 Yellow。
- Stage 9 `gate.legal.escalation_declared` 驗證 tier 與產出深度一致。

## 驗證

- Tier 是否在回覆早段明說（不是藏在結尾）？
- Yellow 是否列出**具體**需覆核條款，而非籠統一句「建議諮詢律師」？
- Red 是否確實沒有實質建議，且 Escalation Card 完整？
- 是否有任何 tier 判定是憑直覺而非對照本表？
