# Counterparty Due Diligence（三層背景調查）

深度為**公開來源核實 + 風險旗標**。目的不是產出一份公司資料附錄，而是回答：
**這個對手方讓我方需要改哪些條款？**

```text
Layer 1  Counterparty Identity   → 這個法人存在嗎？我要簽的是誰？
      ↓
Layer 2  Corporate Status        → 它現在正常營運嗎？
      ↓
Layer 3  Risk Signals            → 有什麼會讓我方受害的訊號？
      ↓
Output   Diligence Card          → risk flag → 條款調整建議
```

任一層無法完成時，**不跳過**：標記 `unverified` 並說明它讓哪個條款建議降級。

## Layer 1 — Counterparty Identity

確認「我要簽的是誰」。最常見的損失來源不是條款不好，而是簽錯主體。

| 查什麼 | 為什麼 |
| --- | --- |
| 法人全稱（與登記完全一致） | 簡稱／商標名不是法人名；契約當事人寫錯影響主張 |
| 登記編號（統一編號 / 註冊號） | 唯一識別；同名公司不罕見 |
| 登記地與實際營業地 | 決定法域、送達地址、執行地 |
| 法人形式 | 股份有限公司／有限公司／分公司／辦事處／個人 |
| **簽約主體 vs 集團母公司** | 對方常用資本額小的子公司簽約 |
| **代表人與簽署權限** | 非代表人簽署需授權書；無權代理是常見爭議 |
| 分公司 / 辦事處 | 分公司有無獨立締約能力依法域而異；辦事處通常不能締約 |

**Red flag**：對方要求用集團某個「品牌名」或未登記名義簽約。

## Layer 2 — Corporate Status

確認「它現在正常運作」。存在 ≠ 正常營業。

| 查什麼 | 訊號 |
| --- | --- |
| 公司狀況 | 核准設立 / 停業 / 解散 / 廢止 / 撤銷 / 重整 |
| 設立日期 | 成立未久 + 大額交易 = 風險 |
| 資本額 | 與交易金額量級是否相稱 |
| 增減資紀錄 | 近期大幅減資是警訊 |
| 營業項目 | **問兩件事**：(1) 是否涵蓋本交易標的（超營業項目影響效力依法域而異）；(2) **對手方是否處於受法規監理產業**（需品質管理系統、批次追溯或稽核保存義務者，例如受監理之製造、金融、醫療、食品、運輸）→ 若是且交付標的會產生追溯／履歷／稽核類資料，觸發 `REGULATED_INDUSTRY_COUNTERPARTY` |
| 稅籍登記狀態 | 是否仍為營業中 |
| 上市櫃公司財報 | 公開財務體質（若適用） |
| 實質營運跡象 | 官網、聯絡方式、員工規模、實體地址是否一致 |

**Red flag**：資本額遠低於交易金額 + 成立未滿一年 + 無實質營運跡象 → 空殼疑慮。

## Layer 3 — Risk Signals（九類）

| # | 訊號 | 查什麼 |
| --- | --- | --- |
| 1 | **是否存在** | 登記查詢無此法人 → 停止 |
| 2 | **是否正常營業** | 停業／解散／廢止／撤銷 |
| 3 | **重大新聞** | 財務危機、負責人爭議、產業事件、大量裁員 |
| 4 | **是否被制裁** | 制裁名單與出口管制實體清單（命中 → **Red tier**，停止交易並升級） |
| 5 | **重大裁判** | 民事給付／損害賠償／營業秘密案件；是否為常被訴主體 |
| 6 | **政府黑名單** | 各主管機關的違規／不良廠商公告 |
| 7 | **政府採購停權** | 拒絕不良廠商名單（影響能否作為採購案分包） |
| 8 | **破產 / 重整** | 破產、重整、清算、資產保全 |
| 9 | **欠稅（若公開）** | 欠稅公告、行政執行紀錄 |

### 來源分層

| 目的 | 台灣 | 國際 |
| --- | --- | --- |
| 法人存在與登記 | 經濟部商工登記公示資料查詢；法人／團體登記 | 當地公司登記機關（各國 registry）；跨國聚合平台僅作線索 |
| 公司狀況與資本額 | 同上 | 同上 |
| 財務 | 公開資訊觀測站（上市櫃） | 當地公開申報系統（若有） |
| 稅籍 | 財政部稅籍登記查詢 | 依當地制度 |
| 裁判 | 司法院裁判書查詢系統 | 當地法院公開系統 |
| 勞動 / 環保違規 | 主管機關違規查詢與列管名單 | 依當地制度 |
| 政府採購停權 | 政府電子採購網不良廠商公告 | 依當地制度 |
| 制裁 / 出口管制 | — | 主要制裁機關的名單與出口管制實體清單 |
| 實質受益人（UBO） | 依當地制度 | 有 UBO registry 的法域優先查 |

**來源可信度**：依 [`../reference-sources.md`](../reference-sources.md) §來源可信度階層。
官方登記與法院系統為 A 層；新聞為 D 層（僅作線索，需回溯官方來源）。

**國際加查**：註冊地是否為常見紙上公司法域；集團架構（誰有資產）；
資產所在地是否為紐約公約締約國（決定仲裁裁決可執行性，見
[`../jurisdiction.md`](../jurisdiction.md) §5）。

## Risk Flag → 條款影響（本 slice 的核心產出）

| Flag | 觸發 | 條款調整建議 |
| --- | --- | --- |
| `ENTITY_NOT_FOUND` | 登記查詢無此法人 | 停止；要求對方提供正確主體 |
| `SHELL_ENTITY_SUSPECTED` | 資本額 ≪ 交易額 + 成立未久 + 無營運跡象 | 母公司保證／履約保證金／提高預付比例／降低我方先期投入 |
| `SIGNATORY_AUTHORITY_UNVERIFIED` | 簽署人非登記代表人且無授權書 | 要求授權書並列為簽署前提；契約加陳述與保證條款 |
| `NOT_OPERATING` | 停業／解散／廢止／重整 | 停止；或要求由正常營運主體承接 |
| `LITIGATION_HISTORY_PAYMENT` | 多起給付／損賠訴訟 | 縮短付款節點、提高擔保、加速終止權 |
| `SANCTIONS_HIT` | 制裁或出口管制名單命中 | **Red tier**：停止交易並升級 |
| `PROCUREMENT_DEBARRED` | 政府採購停權名單 | 不得作為政府採購案分包；一般交易須評估聲譽風險 |
| `INSOLVENCY_RISK` | 破產／重整／大幅減資／欠稅 | 預付比例、擔保、破產即為立即解除事由 |
| `ENFORCEMENT_GAP` | 資產所在地不利執行 | 改仲裁地／要求當地擔保或母公司保證 |
| `SCOPE_MISMATCH` | 營業項目未涵蓋本交易 | 確認締約能力；必要時加陳述與保證 |
| `REGULATED_INDUSTRY_COUNTERPARTY` | 對手方屬受法規監理產業，且交付標的會產生其法規遵循所需的追溯／履歷／稽核資料 | (1) 增訂**資料保存期限與終止後匯出義務**；(2) 擴充責任限制的排除清單，明文涵蓋「對手方法規查核未通過」與「主管機關處分」類衍生損失（標準的停工／生產／營業／預期利益清單未必涵蓋）；(3) 該產業的具體法規義務標 `unverified`，列為律師覆核項 |

每個 flag 必須附：**來源（含層級）+ 查核日 + confidence（confirmed / probable / unverified）**。

> **Flag 的定義**：risk flag 的價值在於它**改變了哪一條條款**，不在於它描述了對手方什麼特徵。
> 任何背調欄位若無法對應到具體條款調整，就只是資料，不要列為 flag。
> 來源：[`feedback/history/legal/common/2026-07-30_221637-counterparty-business-scope-drives-clause-terms.md`](../../../feedback/history/legal/common/2026-07-30_221637-counterparty-business-scope-drives-clause-terms.md)

```markdown
| # | 訊號 | 結果 | 來源 | 查核日 | Confidence |

| Flag | 依據 | 建議的條款調整 | 已納入 Decision Register？ |

```

## 隱私與範圍邊界

- 只蒐集**與締約風險相關**的公開資訊。不做個人生活背景調查。
- 對象是**法人與其代表人的商業角色**，不是私人個資彙整。
- 不使用需要規避存取限制的來源；不使用來源不明的洩漏資料。
- 產出不寫入無關第三人的個資。

## 驗證

- 三層是否都跑過，或明確標出未能核實項？
- 九類 risk signal 是否逐項有結果（含「查無」）？
- 每個 flag 是否對應到**具體條款調整**，並已進 Decision Register？
- 每筆結論是否有來源層級與查核日？
- `SANCTIONS_HIT` 是否已觸發 Red tier 升級？
