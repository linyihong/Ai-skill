# Researcher Note Contrast（研究帳／筆記對照）

對照個人研究帳、社群筆記與公開 A／B 來源。  
**語言：source authority（D＝discovery）**。**禁止**把任何個人帳升成「Expert Knowledge」primitive（H6 reject）。

## 何時使用

- Watchlist 含個人研究帳（使用者本地設定；canonical 不存帳號清單）  
- `name-diligence`／`theme-research`／`periodic-sweep` 碰到「大神說…」  
- 需要把筆記變成 **可反對照**，而非權威背書

## 對照表模板

```markdown
## Note identity
- Handle / title: <redacted or public handle>
- Note as-of: <date>
- Topic overlap: <theme | ticker>

## Claims extracted
| # | Claim from note | Note authority (usually D) | Overlap with our thesis? |

## Contrast
| Claim # | Supporting A/B? | Conflicting A/B? | Agree / Disagree / Unknown | Why |
| --- | --- | --- | --- | --- |

## Freshness
- Note age vs market moves since then
- Superseded? (later note / filing)

## Use in recommendation
- Allowed role: discovery / color / checklist prompt
- Forbidden role: sole support for buy/sell/allocate
```

## 規則

1. **每條筆記 claim 單獨列**，不要「該帳整體看多」。  
2. **Agree 仍要 A／B**：同意筆記 ≠ 證據升級；同意只表示敘事對齊。  
3. **Disagree 要寫清**：是事實衝突、時間窗不同，還是策略偏好不同。  
4. **時效**：事件後未更新的筆記標 `stale-risk`。  
5. **Sanitization**：不把私人轉發、未公開群組內容寫進 canonical；專案 evidence 去敏。

## 與 D 級天花板

| 若只有… | Recommendation 上限 |
| --- | --- |
| D 筆記 | 觀察／待查／列 open question |
| D＋C 轉述 | 仍不得寫「最適配置」 |
| D＋A／B 交叉且一致 | 可以敘事輔助；決策強度跟 A／B |

## 明確拒絕的框架

| 拒絕 | 改用 |
| --- | --- |
| Expert Knowledge | Source authority D＋contrast |
| 「大神已驗證」 | 「個人研究帳 claim，待 A／B」 |
| 把 watchlist 帳號寫進本庫 | User-local settings only |
